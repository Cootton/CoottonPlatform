# Admin product intake v1 — 2026-10-04

Owner requests complete product intake. This extends D01/D02/D03 with executable **draft intake**, not checkout or publication. Existing product/SKU identities, canonical ownership, immutable codes, exact decimal strings, version/idempotency/audit/outbox remain authoritative.

- `saveIntake` atomically replaces sourced fabric rows and size-chart cells and creates missing color/size SKUs; existing SKUs are never renamed/deleted. Maximum 100 SKU combinations and 200 chart cells in this initial bounded command. Existing SKU omissions are rejected; no silent archival. All dictionaries must be active and correctly typed. Form applicability is explicit and category-controlled. CLEANFIT remains inactive; no custom form input.
- Each entered origin/care/fabric/chart/price/stock statement references one immutable private declaration written by the authenticated Admin. Declaration records input provenance; it is **not verification or approval**. Unknown GSM is explicit, never zero. Quantities and VND use integer strings, GSM/cm use positive decimal strings up to two decimals. No HTML or remote image URLs accepted.
- D02 `pricing_offering`, `pricing_price_version`, `pricing_tier` are draft relational records (B2C/B2B same SKU). No price activated, no effective interval invented. New draft sequence preserves older drafts. B2B tier first threshold1; thresholds ascend, unit prices do not increase. Blank prices mean missing; never infer zero/free. Price UI does not approve offers or enable seller modes.
- D03 stock_position is one shared SKU/location identity, with onHandSellable/reserved/version. Initial single seller location is an Admin declaration, not fabricated physical warehouse. Audited intake correction must remain >=reserved; movement records previous/new quantities and evidence. No holds/orders exposed. Blank stock means unconfigured, not zero. No B2C/B2B stock duplication.
- `uploadImage`: JPEG/PNG/WebP only, input <=3MiB, <=16M pixels, one frame, dimensions <=8192. Backend decodes/rotates/resizes to <=1600px and WebP, strips metadata, computes hash. Persist only processed object to private `COOTTON_MEDIA_BUCKET`, immutable object path `/media/{command UUID}/{sha256}.webp`; create-only writes and same-path deterministic retry. Media is pending approval; rights declaration required. Maximum20/product, alt1..300. No public object or arbitrary filesystem/URL fetch. Preview is authenticated and returns bounded base64 WebP; no bearer query parameter. Missing bucket/rights grant fails closed. Out-of-transaction immutable upload may leave orphan after rejected DB command; record and reconcile privately; no automatic purge.
- Migration003 is additive; never edit applied migrations001/002. Adds applicability, draft pricing, stock/location/movement and role grants only for fixed validated commands. It seeds only owner-defined categories/forms/brand and standard controlled size/color/measurement/country definitions with explicit provenance, never real product facts, prices, stock or images. Admin dictionary extension is audited; no schema editing from UI.

Activation requires reviewed migration003, scoped database grants and a private media bucket with API create/read objects only. No delete/admin IAM, storage public access, financial grants or publication activation. Source completion alone is not deployment evidence.
